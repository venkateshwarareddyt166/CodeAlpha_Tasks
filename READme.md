Aura Quote is a simple and elegant web application that generates inspirational and motivational quotes randomly.
Users can generate new quotes, save their favorite quotes, and share them easily. 
The project provides a clean user interface and enhances user experience with a favorites section.

Features
- Generate random motivational quotes.
- Save quotes to Favorites.
- Generate unlimited quotes.
- Share quotes with others.
- View all saved favorite quotes.
- Clean and responsive user interface.

Technologies Used
Python
Flask
HTML5
CSS3
JavaScript
Jinja2 Templates

Steps to Run the Project
1. Clone the Repository
2. Move to Project Directory
3. Install Dependencies
4. Run the Application
5. Open in Browser

Usage
Open the Aura Quote application.
Click on "Generate New Wisdom" to get a random quote.
Save your favorite quotes using the Favorite option.
Visit the Favorites section to view saved quotes.
Share inspiring quotes with friends and family.
