This project is a modern and user-friendly quiz platform designed to provide an engaging learning experience through
category-based questions, timed responses, and instant answer validation.

Project Overview 
The application presents users with multiple-choice questions from different domains such as: 
- History
- Geography
- Technology
and more.
Users must select an answer within the given time limit. Once an answer is locked, the system instantly validates the response
 and displays whether it is correct or incorrect.

Key Features
1.Interactive and responsive user interface
2. Multiple question categories
3.Countdown timer for each question
4.Answer locking mechanism
5.Real-time answer validation
6.Smooth navigation between questions
7.Professional dark-themed UI/UX design
  
Technologies Used
Python – Backend development and application logic
Flask – Web framework for handling routes and server-side operations
HTML5 – Structure and content of web pages
CSS3 – Styling and responsive design
JavaScript – Quiz functionality, timers, and user interactions

Usage
Launch the application
Start the quiz from the home screen
Read each question carefully
Select the correct answer before the timer runs out
Submit your answer and receive instant feedback
Continue until all questions are completed
View your final score and performance summary

Steps to Run the Project
1.Clone the repository
2.Navigate to the project directory
3.Install dependencies 
4.Run the application

TASK 2-RANDOM QUOTE GENERATOR
Aura Quote is a simple and elegant web application that generates inspirational and motivational quotes randomly.
Users can generate new quotes, save their favorite quotes, and share them easily. 
The project provides a clean user interface and enhances user experience with a favorites section.

Features
- Generate random motivational quotes.
- Save quotes to Favorites.
- Generate unlimited quotes.
- Share quotes with others.
- View all saved favorite quotes.
- Clean and responsive user interface.

Technologies Used
Python
Flask
HTML5
CSS3
JavaScript
Jinja2 Templates

Steps to Run the Project
1. Clone the Repository
2. Move to Project Directory
3. Install Dependencies
4. Run the Application
5. Open in Browser

Usage
Open the Aura Quote application.
Click on "Generate New Wisdom" to get a random quote.
Save your favorite quotes using the Favorite option.
Visit the Favorites section to view saved quotes.
Share inspiring quotes with friends and family.
